How It Works

Step 1: Upload a road video file through the simple upload interface. Step 2: Select your detection module (Lane Detection or Pothole Detection). Step 3: The system processes each video frame using either custom computer vision algorithms for lane detection or YOLO deep learning model for pothole detection. Step 4: View the processed video with visual overlays showing detected lanes or potholes drawn directly on the frames. Results are streamed in real-time with instant playback capability for both detection modules.
